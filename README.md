# Plugin Paheko pour générer des factures au format Factur-X en hébergement mutualisé

Paheko inclut ce qu'il faut pour générer du Factur-X avec prince, weasyprint ou ghostscript :

<https://fossil.kd2.org/paheko/wiki?name=Configuration%2FFactur-X>

Si vous êtes sur un hébergement mutualisé et que vous ne pouvez pas installer de logiciel dessus, alors ce plugin en pur PHP permettra de créer des Factur-X.

**AVERTISSEMENT :** Ce plugin n'est pas maintenu, ni l'association Paheko, ni ses développeur⋅euses ne travaillent dessus, et **aucun support ne sera fourni**.

Il est fourni à titre de base de travail si une ou des personnes de la communauté souhaitent continuer à le maintenir.
