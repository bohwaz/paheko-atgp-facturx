# Plugin Paheko pour générer des factures au format Factur-X en hébergement mutualisé

Paheko inclut ce qu'il faut pour générer du Factur-X avec prince, weasyprint, DomPDF ou chromium+ghostscript :

<https://fossil.kd2.org/paheko/wiki?name=Configuration%2FFactur-X>

Ce plugin en pur PHP permet de créer des Factur-X à partir de Chromium, si on n'a pas Ghostscript installé. Ceci n'est plus supporté.

**AVERTISSEMENT :** Ce plugin n'est pas maintenu, ni l'association Paheko, ni ses développeur⋅euses ne travaillent dessus, et **aucun support ne sera fourni**. Il est uniquement fourni à titre d'archive historique.
